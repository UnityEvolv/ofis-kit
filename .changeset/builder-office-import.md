The builder reads an office out of an SVG that carries its rooms. Upload a background drawn to the office convention and the rooms step opens with its rooms and user areas placed, each rule problem shown where it is, and a way to start blank instead; a file with a script, an embedded document or an outside link is refused with the element named; a dark image must carry the same rooms as the light one. "Check a file" reports what an import would say without loading anything. The prompt step offers the generated office prompts, one per theme and view, beside the picture prompt (`officePrompts` on `BuilderSteps` and `PromptStep`). The save bar notes a room against the canvas edge, where a festival frame would cover its bar.
